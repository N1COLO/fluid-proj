핵심 설계 파라미터 선정 (1/3)

📐
블레이드 출각 β₂
변수 범위: 15° ~ 45°

오일러 방정식에 의해 결정되는 근본 원리. 97.22 kg/s 고유량 조건에서 출각이 과도하면 수력 손실이 급증하므로 최적 탐색이 필수적이다.

이론 근거: 유량↑ → 출각 영향 더 증폭 (고유량 효율 민감도 증가)
Cavitation and wear in industrial pump operation (Vacuum Journal, 2019)
🔢
블레이드 개수 N_b
변수 범위: 5 ~ 9개

1,250 RPM ← 낮은 비속도(N_s) 조건. 블레이드 수를 늘려 유동 안정성을 확보하는 전략이 효과적. 5개→9개 범위에서 최적값 탐색.

이론 근거: 저속·고유량 → 블레이드 간격↑ → Flow Separation 위험
Effect of Blade Number on Centrifugal Pump (ANSYS, Academia 2023)
🔩
Tip Clearance (Shroud)
저속 조건에서 영향 더 큼

1,250 RPM 저속 → 팁 누설 유동의 상대적 비중이 증가. NASA 연구에 따르면 회전수↓일수록 Tip Clearance가 Head 계수에 미치는 영향이 더 뚜렷함.

Effect of tip clearance on axial-flow pump performance (NASA TR, 1973)
✂️
TE 형상 및 두께
고유량에서 효과 극대화

97.22 kg/s 고유량 → Trailing Edge 후류 압력 손실이 크므로, TE 두께를 줄일 때 얻는 효율 개선이 소유량 대비 상대적으로 더 크다.

Trailing edge shape optimization for centrifugal pump (Energy Technology, 2025)

Section 05 · DOE 샘플 설계

실험계획법 (DOE) — 샘플링 전략

🎲 Optimal Latin Hypercube Sampling (LHS) 선택 이유

단순 격자(Full-Factorial)는 5개 변수 × 다수 수준 시 케이스 수가 기하급수적으로 증가한다. LHS는 전체 설계 공간을 균등하게 커버하면서 최소 샘플로 최대 정보를 확보한다.

🔑 50 Case 설정의 논리
Kriging 대리모델의 정확도는 샘플 수에 비례한다. 5개 설계 변수에 대해 일반적으로 변수당 10개 이상의 샘플이 권장된다 (5 × 10 = 50). 블레이드 수는 이산 변수이므로 5가지 값을 각각 10점씩 별도 샘플링하여 이산-연속 혼합 설계 공간을 효율적으로 커버한다.

Section 06 · Kriging 대리모델

Kriging 대리모델 — 이론 및 구현

📐 Kriging 모델의 수학적 정의
ŷ(x) = f(x) + Z(x)
• f(x): 전역 추세 함수 (global trend)
• Z(x): 평균 0, 분산 σ²의 확률 함수 (국소 편차)
• Covariance: Cov[Z(xᵢ),Z(xⱼ)] = σ² R(xᵢ,xⱼ)
• R: 상관 함수 (가우시안 커널 적용)
Kriging은 기존 샘플 데이터를 100% 통과(exact interpolation)하면서 새로운 점을 예측

Section 06 · 파라미터 영향 분석

설계 변수 영향 분석 — 물리적 해석

📐 블레이드 출각 β₂ 증가 효과
오일러 방정식: H = u₂C_u2/g. 출각↑ → C_u2↑ → Head↑. 단, 과도한 출각은 유동 분리를 초래해 효율 저하. 최적 출각은 Head-Efficiency 트레이드오프 균형점.
🔢 블레이드 수 증가 효과 (5→8개)
유동 경로 분할 → 블레이드 간 유속 분포 균일화 → Streamline 안정성↑ → 압력 전달면 확대 → Head↑ · Eff↑. 9개 이상에서 Blockage 증가로 Head 감소.
🔩 Tip Clearance 감소 효과
블레이드 팁 누설 유동 감소 → 에너지 손실↓ → Head↑ · Eff↑. 1,250 RPM 저속 조건에서 팁 누설의 상대적 기여가 크므로 감소 효과가 뚜렷하다.
✂️ TE 두께 감소 & Wrap Angle 최적화
TE 두께↓ → 후류 와류(wake) 감소 → 출구 압력 손실↓ → Eff↑. Wrap Angle 최적화 → 블레이드 경로 완만 → 유동 박리 억제 → 전 유량 범위 성능 안정.
📊
설계 변수 민감도 분석 그래프
각 변수가 Head / Static Efficiency에 미치는 영향도 상대 비교 차트 (Kriging 기반 DOE sensitivity plot 삽입)

Section 07 · 고찰

고찰 및 한계점

✅ 본 연구의 성과
  • Head ≥ 37m, Static Eff. ≥ 80% 동시 달성
  • 50 Case 대규모 DOE로 설계 공간 충분 탐색
  • Kriging 대리모델 오차 < 1% — 신뢰성 확보
  • 변수당 논문 근거 기반 선정 — 물리적 타당성
⚠️ 한계점 및 개선 방향
  • SST k-ω 난류 모델 — LES 대비 박리 예측 한계
  • 설계 공간 범위 내 국소 최적해 가능성 존재
  • 단일 유량 조건 해석 — 설계점 외 성능 미검증
  • 격자 품질 일부 구역 경고 (wall y+ 최적화 여지)
🔭 향후 연구 방향
다목적 최적화 확장 — Head와 Efficiency를 동시에 최대화하는 Pareto 최적화(NSGA-II 등) 적용
유량 곡선 전체 검토 — 설계점 외 부분 유량/과유량에서의 성능 검증
실험 검증 — CFD 최적 설계의 실물 제작 후 성능 곡선 측정으로 해석 신뢰성 최종 확인
